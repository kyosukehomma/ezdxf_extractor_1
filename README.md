# DXF 横断図 赤黄チェッカー

`input` フォルダ内のDXF横断図から測点・種別・数量を抽出し、Excelテンプレートへ転記するデスクトップツールです。

## 処理内容

1. `input/*.dxf` を読み込む
2. DXFの `TEXT` と `LINE` から土工表、測点、種別、単位、数量を抽出する
3. `template/01-01-03土工.xlsx` の「入力」シートへ転記する
4. 必要に応じて明細・集計シートを測点数まで拡張する
5. DXFごとのExcelを `output/exec_YYMMDD_HHMMSS/` に保存する
6. 処理済みDXFを `input/used_YYMMDD_HHMMSS/` へ移動する

処理前のDXFを残す必要がある場合は、あらかじめ別の場所へコピーしてください。

## ディレクトリ構成

```text
.
├── input/                         # DXF配置先（DXFはGit管理対象外）
├── output/                        # 実行時に自動作成
├── template/
│   └── 01-01-03土工.xlsx
├── tools/
├── oudan_red_yellow_checker.py
└── requirements.txt
```

## 実行環境

- Python 3
- Tkinter
- `ezdxf`
- `openpyxl`

Ubuntu／WSLでTkinterが未導入の場合:

```bash
sudo apt install python3-tk
```

Python依存パッケージの導入:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 実行

1. DXFファイルを `input/` に配置します。
2. 次のコマンドを実行します。

```bash
python oudan_red_yellow_checker.py
```

3. 確認ダイアログで処理を開始します。

## 現在の主な前提

- 抽出対象はモデル空間の `TEXT` とネイティブの `LINE` エンティティです。
  `MTEXT` は対象外です。
- 土工表は `D-MTR-TXT` 系レイヤー上で、同一行に
  `種別・単位・数量` が左右2組並ぶヘッダーから検出します。
- ヘッダーと同じレイヤーの水平・垂直LINEを接続成分に分け、
  主表と、存在する場合は直下の「作業土工」小表を抽出領域にします。
- `種別・区分・単位・数量` 形式の階層表では、種別と区分を組み合わせます。
  上部路床と下部路床は幅員区分ごとに合算して「路床盛土」へ転記し、
  法面整形工は左右の数量を別々に転記します。床掘・埋戻(C/D)は
  「作業土工1」へ、路肩盛土は「路床」と集計表へ転記します。
- `記号・種別・区分・数量` の列を持つ形式では、記号列を使用せず、
  `D-MTR-LINE` の罫線行と `種別・区分・数量` の組み合わせで識別します。
  左右区分のない切土法面整形と盛土法面整形は `(左)` に転記し、
  `(右)` は空白にします。
- 土工表の直上に本線・ランプの路線名が明示されているDXFは、
  形式にかかわらず「本線」の表だけを抽出します。全表に路線名が
  ないDXFは、従来どおり全表を本線として扱います。路線名のある表と
  ない表が混在する場合は、誤判定を避けるため処理を停止します。
- 測点候補は `D-BMK-HTXT` レイヤー上の `NO.{数値}` または
  `NO.{数値}+{数値}` です。
- `D-BMK` レイヤー上に完全一致する `CL` がある場合は、
  `土工表 → CL → 測点` の順に中心測点を選びます。
- `CL` がない場合は、各土工表へ割り当てられる測点候補が1件のときだけ採用します。
- 表・データ群・測点を一意に対応付けできないDXFは、誤転記を避けるため
  Excelを出力せず、元のDXFも移動しません。
- 測点間隔は20mまたは100mのうち、測点列が厳密に増加する最小値を採用します。
- 25件を超える階層型の結果では、明細行、合計式、印刷範囲、名前定義、
  入力補助式、チェックシートを測点数に合わせて拡張します。
- 明細の数量計算は、抽出した測点列を連続区間として扱います。
  大きな測点間隔を別区間として分割する必要がある場合は、業務上の確認が必要です。
- Excelテンプレートのシート名「入力」と2行目の種別見出しに依存します。
- テンプレートに存在しない種別は転記されません。
- Excel数式の再計算はExcelでブックを開いた際の再計算に依存します。
- `05_本線横断図.dxf` の法面整形工はDXF上の単位表記が `m2`、
  Excelテンプレート上は法長 `(m)` です。数値は種別と左右区分に基づいて転記します。

## テスト

```bash
python -m unittest discover -s tests -v
```

ローカルの検証用DXFと確認済みExcelがある場合は、正常ケースのセル値比較と、
本線横断図77表の抽出・中心測点・全行ダイジェスト・明細/集計式の拡張と、
種別型横断図103表から本線52表だけを選ぶ記号非依存抽出・
全行ダイジェスト・法面整形の左右転記も確認します。
これらのファイルがない環境では、該当するローカル回帰テストだけがスキップされます。
